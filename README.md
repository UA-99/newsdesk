Desktop RSS reader built with Electron. Provides:

- Unified list of configured news sources
- Reader mode toggle with ad blocking
- Sidebar controls to filter/search feeds and customize source colors

## Installation

Install dependencies and build distributables with the helper script:

```bash
./install.sh
```

The script requires Node.js 20+ and npm. Pass `--skip-build` to only install dependencies or `--only-build` to rebuild the packaged app after dependencies are installed.

## Development

Install dependencies and start the app:

```bash
npm install
npm start
```
